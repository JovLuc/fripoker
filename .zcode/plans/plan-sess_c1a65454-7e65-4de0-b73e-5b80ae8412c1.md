# fripoker TypeScript 全量重构方案

## 目标与原则

1. **游戏行为 100% 保持**：起始 2000 币、盲注 10/20 固定、6 席不足补机器人、不自动开下一手、全员准备才开局、借贷 ×1.1 计息、作弊口令、断线重连、聊天 80 条上限、无操作超时等全部规则不变。
2. **架构重新分层**：修复现有代码的结构性问题（全局可变状态、ws 动态挂属性、跨层字段污染、if-chain 路由、死代码）。
3. **前后端共享协议类型**：消息协议从「隐式约定」变为 `src/shared/protocol.ts` 中的可辨识联合，前后端同一份类型定义——这是本次重构最大的架构收益。
4. **引入构建链**（推翻旧 AGENTS.md 第 5 条约定，文档同步重写）：服务端 tsc → dist，前端 Vite 构建，测试 vitest。

## 关键架构决策（对比旧代码）

| 旧问题 | 新方案 |
|---|---|
| `rooms` Map 全局导出、`lobbySockets` 裸全局 | `RoomRegistry` / `LobbyHub` 类实例，index.ts 装配传入（可测性） |
| ws 对象动态挂 playerId/nickname | `ClientConn` 包装对象，连接注册表统一管理 |
| `game.readyIds` 由 rooms.js 动态挂上，engine 不感知 | readyIds 归 Room 实体，GameState 保持纯规则 |
| index.js 12 个 if 分支路由 | `Record<ClientMessageType, Handler>` 类型化路由表 |
| handTimer/tickTimer/handStop/emptyTimer 四个死/混用定时器字段 | Room 只留 `botTimer` 一个真实定时器概念 |
| 死代码（broadcastRoomList、startRoomLoop、MIN_PLAYERS、actionDeadline、showdownName、evaluate7 死导入） | 全部移除 |
| 客户端平铺字段 / 服务端 {type,payload} 不对称 | 双向统一 `{ type, payload }`（前后端同仓同发，无兼容负担） |
| 前端 638 行单组件、2s 轮询 interval 无法清理、ensureProfileThen 竞态、role 双处推导 | 组件化 + composable；interval 持引用并清理；WS 客户端 promise 化；role 单一推导函数 |
| bot 惰性 require、观战 viewerId 每次广播随机 | 顶部 import；每连接稳定 viewerId |
| 观战者序列化噪声 | 同上 |

保持不变的东西：`poker/` 参考目录不动；localStorage 四个 key 不动（老用户无缝重连）；CSS 类名与视觉结构不动；`/fpk` 别名 + BASE_PATH + SPA fallback + 302 裸前缀重定向逻辑原样平移。

## 实施步骤

1. **脚手架**：新 package.json（type:module；dev 依赖 typescript/tsx/vite/@vitejs/plugin-vue/vue-tsc/concurrently/vitest/@types/ws，运行依赖 ws+vue）、三份 tsconfig、vite/vitest 配置、新 index.html，`npm install`。
2. **shared 层**：protocol.ts + constants.ts，把两份调研报告中的完整字段清单落成类型。
3. **引擎平移 + 单测**：game/ 六个文件从 engine.js 平移（算法逐行保留），先写 vitest 单测锁行为：牌型 9 类排序与踢脚、A2345 轮子顺、边池三层分配、余数前 N 名 +1、弃牌获胜不摊牌、min-raise 拒绝、全下不足跟注、整手筹码守恒、借还与 ×1.1 计息宽限手、repay 分期 min(500,debt)。
4. **bot/cheat 平移**：botDecide 增加一条「永不返回非法动作」的性质测试。
5. **服务端编排**：net/ + lobby/ + room/ 五文件 + index.ts 装配与路由表。
6. **端到端冒烟测试**（vitest 内）：真实起服务（临时端口）+ ws 假客户端走完整流程——建房→两真人→开局→脚本化打一手到摊牌→断言筹码守恒与快照字段；含重连认座、破产观战、ready 流转。
7. **前端重写**：ws 客户端 → stores → 组件与样式平移 → vue-tsc 清零。
8. **构建验证**：`npm run build` 产出 dist/，`node dist/server/index.js` 起服务手动/浏览器冒烟。
9. **Docker**：改多阶段 Dockerfile，`docker build` 验证。
10. **文档重写**：根 AGENTS.md（新模块地图、脚本、环境变量、删除旧「禁 TS」条款）、src/server/AGENTS.md、docs/client.md（协议段指向 shared/protocol.ts）。
11. **清理**：删除 server/*.js、js/、css/、vendor/（vue 改 npm 依赖）；`npm test && npm run build` 作为最终门禁。
